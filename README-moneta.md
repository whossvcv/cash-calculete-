# Монетка — Telegram-бот для учёта трат

Пишете боту «кофе 150» — он записывает трату, сам определяет категорию, показывает статистику,
предупреждает о месячном лимите, вечером напоминает записать траты и выгружает всё в CSV.

## 1. Создать бота (1 минута)
1. В Telegram откройте @BotFather → `/newbot`.
2. Придумайте имя (например, «Монетка») и username, оканчивающийся на `bot`.
3. BotFather пришлёт **токен**. Никому его не показывайте (и мне тоже): по нему можно управлять ботом.
4. По желанию: `/setdescription`, `/setuserpic`, `/setabouttext` — чтобы бот выглядел привлекательно.

## 2. Запустить на своём компьютере (проверка)
```
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен"        # Windows: set BOT_TOKEN=ваш_токен
python bot.py
```
Откройте бота в Telegram и нажмите /start.

## 3. Выложить, чтобы работал круглосуточно
Подойдёт любой хостинг, где можно запустить Python-процесс:
- **Railway / Render / Fly.io:** загрузите папку в GitHub, создайте проект из репозитория,
  добавьте переменную `BOT_TOKEN`, команда запуска: `python bot.py` (тип сервиса — worker).
  Подключите постоянный диск (Volume) и задайте `DB_PATH=/data/moneta.db`,
  иначе база будет стираться при каждом обновлении.
- **Свой VPS:** `python bot.py` под systemd или в Docker/tmux.

## Что умеет
- Запись текстом: `кофе 150`, `аренда 12к`, `+30000 зарплата`
- Автокатегории (еда, транспорт, развлечения и др.) и смена категории кнопкой
- `/stats` — неделя / месяц / всё время, `/history` — последние записи с удалением
- `/limit 30000` — месячный лимит и предупреждения на 80% и 100%
- `/export` — CSV для Excel и Google Таблиц
- `/currency`, `/tz`, `/remind on|off` — валюта, часовой пояс, вечернее напоминание в 21:00
